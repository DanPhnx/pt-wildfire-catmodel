# Portuguese Wildfire Catastrophe Loss Model

A parametric catastrophe loss model for mainland Portugal, built as a portfolio
project demonstrating frequency/severity modeling, Monte Carlo simulation, and
tail-risk metrics (VaR, Expected Shortfall) as used in reinsurance pricing.

## Project structure

```
main.py                 Reproducibility entry point: runs each phase notebook in order
wildfire_model.py       Logic shared across phases (fire-day event construction,
                        the train/hold-out split)
distribution_fitting.py Phase 2's fitting/testing/plotting logic (frequency and
                        severity models, goodness-of-fit tests, bootstrap CIs,
                        diagnostic plots) - per the PRD's "notebooks for EDA
                        only," 02_distribution_fitting.ipynb imports and calls
                        this rather than defining the logic itself
monte_carlo.py          Phase 3's simulation engine (frequency/severity sampling,
                        severity tail cap, risk metrics, convergence check,
                        diagnostic plots) - same "notebooks for EDA only" pattern;
                        03_monte_carlo.ipynb imports and calls this
data/raw/               ICNF PRDF export (not committed — large GeoPackage; see
                        Data sources), committed EFFIS CSV (EDA cross-check),
                        live OWID/GWIS/HICP cross-check snapshots, and the loss
                        calibration and anchors tables
data/processed/         Cleaned, per-fire-event CSV, regenerated by 01_eda.ipynb, not versioned
models/                 Fitted distribution parameters and diagnostic plots, committed
                        (small, human-readable JSON + PDF) - Phase 2 (frequency and
                        severity) done
simulation/             Monte Carlo simulation output - Phase 3 results committed
                        (metrics JSON, scenarios CSV)
notebooks/              Jupyter notebooks, one per project phase
docs/                   Phase implementation plan and worklog
```

## Data sources

- **ICNF PRDF (Portuguese Rural Fire Database)**: the primary source for Phase 2-3
  modelling. Real per-fire records from the ICNF national fire database, obtained
  via Zenodo (DOI 10.5281/zenodo.21427772) as a GeoPackage (`fogos.gpkg`, 943 MB,
  **not committed** — see Data download below). Table `Fogos`; columns DHInicio
  (datetime), AreaTotal (ha), Ano, Distrito. **The record used is 2009-2025**
  (mainland only). Cleaning: mainland-only filter, ≥30 ha threshold -> **4,686
  events**. A "fire event" in this model is a mapped mainland fire of at least 30 ha,
  applied to every year (`MIN_FIRE_AREA_HA`), keeping the vast majority of mapped
  area - a deliberate scope choice, not a hidden gap.
- **EFFIS Rapid Damage Assessment fire database**: retained as a committed CSV
  (`data/raw/effis_fire_database_pt_2008_2026.csv`) and used for Phase 1 EDA and
  cross-validation. Real per-fire dates, NUTS2 region locations, and burned areas
  for Portugal, obtained via EFFIS's official Data Request Form (no public API).
  Export runs 2008-04-26 to 2026-09-17; 3,785 events at ≥30 ha (2009-2025,
  mainland). See Phase 1 notebook for the full cross-validation against PRDF.
- **GWIS** (Global Wildfire Information System, JRC/Copernicus): live
  annual fire-count and burnt-area series for Portugal, fetched via Our
  World in Data's CSV mirror. Used only as an independent cross-check, not as a
  modeling input - two real discrepancies were found and documented rather than
  reconciled (see below).
- **Loss calibration (EUR/ha)**: a three-point range in **2025 euros**,
  not a calibrated constant - low ~497 (2024 forest-sector loss/ha, a
  floor), central ~2,296 (ICNF-derived long-run average via OECD/press;
  its price year is assumed, 2021, the smallest possible uplift), high
  ~3,418 (2017 EU Solidarity Fund total direct damage / 2017 mainland
  burnt area). Source figures are restated with Eurostat's Portuguese HICP
  (`data/raw/pt_hicp_annual.csv`). No source publishes verified loss per
  individual fire. The cleaned CSV has `Estimated_Loss_EUR` (each fire's
  own-year euros), `Estimated_Loss_EUR_2025`, and `Loss_Source` (always
  `"modeled (area x central EUR/ha)"` - no source has per-fire loss in
  this window, so every value is modeled and explicitly labelled as such,
  rather than left blank per-fire or presented as observed; see "Data
  gaps and assumptions" in `01_eda.ipynb`). Evidence and candidate
  anchors: `data/raw/loss_anchors.csv`.
- **Copernicus Emergency Management Service (EMS)** and **AGIF/APS
  reporting**: published burnt-area totals and component loss figures for
  2024 (forest-sector loss €67m, insured claims €17m), recorded with
  sources in `data/raw/published_loss_benchmarks.csv` and used as external
  checks. No published total economic loss for 2023 or 2024 was found, so
  these bracket the calibration rather than validate it.
- Full sourcing rationale and known data gaps: see `docs/phase1-plan.md`,
  `docs/worklog.md`, and the "Data gaps and assumptions" section in
  `01_eda.ipynb`.

**Known cross-validation findings (investigated, not hidden):**

- **Count (resolved)**: unfiltered, real EFFIS counts exceeded OWID's
  all-fire counts in some years (e.g. 2022: 1,204 vs 465). The cause was
  the un-thresholded Sentinel-2 records (63-82% of 2020-2025 rows are under
  30 ha), not a MODIS-vs-VIIRS methodology difference as first assumed.
  With the 30 ha filter the EFFIS count is below OWID's in every year with
  OWID data.
- **Area (narrowed, not closed)**: the weighted total-to-total ratio is
  104.7% unfiltered and **102.9%** with the 30 ha filter. By period, the
  filtered ratio is 101.2% for 2009-2019 and 106.5% for 2020-2025
  (111.7% unfiltered), so the small-fire records explain close to half of
  the recent-years excess. The remaining ~6.5% (2020-2025, filtered) is
  an open question.
- **Overdispersion and dependence (PRDF training data)**: annual fire-day
  event counts have a variance-to-mean ratio of ~6.7 (a formal dispersion
  test rejects Poisson: stat=74.0, df=11, p=2.1e-11); annual count and
  median fire size are positively correlated (rho=0.545, p=0.067 — not
  significant at 5%); fires cluster in time (largest single fire-day:
  252,199 ha). Phase 2 therefore fits a Negative Binomial, models fire-day
  events, and the Phase 3 calibration confirmed no frailty amplification
  is needed (see below).
- A separate, confirmed **data-quality defect** in the EFFIS export was
  also found and fixed: 60 redundant duplicate records (same parish, area,
  and timestamp under a different id, all 1-12 ha, ~157 ha in total,
  concentrated in 2021-2025) are removed in `load_effis_fire_database`.

See the notebook's cross-validation section for the full per-year working.

**Reproducibility note:** the EFFIS per-fire database is a static,
one-time export committed to git. The PRDF GeoPackage must be downloaded
separately (see Data download). OWID/GWIS (cross-validation) is a live,
continually-updated source, so that part of the pipeline is capped at
`START_YEAR = 2009` and `MAX_YEAR = 2025` and its fetched CSVs are
committed as the authoritative snapshot.

## Methodology

1. **EDA** (implemented): load the real per-fire EFFIS database, cross-validate
   against independent aggregate sources (PRDF, OWID/GWIS), explore frequency
   and loss patterns
2. **Distribution fitting** (done): events are grouped into fire-day clusters
   (`wildfire_model.build_fire_day_events`), fitted on the confirmed 2009-2020
   training years only using PRDF data (4,686 events → 1,101 training fire-day
   events). Frequency: a formal dispersion test rejects Poisson decisively
   (stat=74.0, p=2.1e-11, var/mean=6.7) and a Negative Binomial is chosen on
   AIC/BIC (114.2 vs 153.6; r=16.78, p=0.155, mean=91.75 fires/year). Severity
   is fitted on **burned area (hectares)**, per the PRD's Technical Decisions
   ("the model fits burned area, not euro losses, and converts to euros at the
   end"): a Lognormal body (mu=5.461 log-ha, sigma=1.523) with a Generalised
   Pareto tail above the 87th percentile (1,490 ha; shape xi=0.786, scale=1,802.3
   ha, 143 exceedances — a heavy tail with infinite theoretical variance, expected
   for a catastrophe model). Threshold at 87th pct (not the nominal 90th): a
   sensitivity sweep found the PRD QQ criterion fails at 90th pct (p=0.015) and
   passes at 87th pct (p=0.078). Euro figures are a deterministic conversion applied
   afterward under the low/central/high EUR/ha scenarios, not baked into the fit.
   The Lognormal body is formally rejected by Anderson-Darling at 5% (a real,
   extreme-tail-concentrated miss, not hidden — see `notebooks/02_distribution_fitting.ipynb`'s
   "Parameter estimates summary"); the GPD tail itself is not rejected (bootstrap
   Anderson-Darling p=0.576). The PRD QQ criterion passes (Spearman rho=0.148,
   p=0.078). Bootstrap 95% CIs reported for every parameter.
3. **Monte Carlo simulation** (complete): Negative Binomial frequency ×
   Lognormal/GPD severity (capped at 5× the historical max fire-day, 1,260,995 ha,
   with ICNF's 6.1M ha mainland burnable-land as an absolute backstop). The fitted
   GPD tail (xi=0.786) has infinite theoretical variance; the cap stabilises the
   simulation while still generating events well beyond anything on record. The
   Phase 3 calibration sweep found the independent model (σ_z=0, ρ=0) already
   overshoots the observed training-period annual-area SD — no frailty amplification
   is needed. Production run: 200,000 scenarios, fixed seed, central EUR/ha=2,296.
   VaR(95%)=€764m (SE=1.21%, PRD criterion <2% ✓), VaR(99%)=€1,777m,
   ES(95%)=€1,380m. All 2021-2025 hold-out years pass. Return-period check:
   2017 falls at the 98.0th percentile (~1-in-51), within the PRD's 1-in-30 to
   1-in-100 target range. See `docs/phase3-frequency-severity-dependence.md` for
   the full calibration rationale and sweep results.
4. **Validation** (not yet implemented): backtesting against held-out years
   (reporting the percentile each falls at), parameter sensitivity, climate
   scenario analysis
5. **Writeup**: technical note summarizing methodology, results, and
   limitations

## Usage

```
python main.py
```

Executes each phase notebook (`notebooks/0N_*.ipynb`) in place, in order,
via `nbconvert`, and reports which ran, failed, or was missing. A
not-yet-started phase's "Run" section is commented out in the notebook, so
it executes cleanly and produces no new output - main.py reports that as
"done" (it ran without error), since whether a phase is actually complete
is the README's Status section and `docs/worklog.md` to say, not something
safe to infer from source text (an earlier version tried to pre-detect
"stub" notebooks this way and silently skipped Phase 2's real work because
of an unrelated, uncalled stub function elsewhere in the same notebook -
don't reintroduce that). Run `python main.py --phase 1` for a single phase,
or open a notebook directly in Jupyter for interactive work.

**Data download.** `01_eda.ipynb` fetches OWID/GWIS (cross-validation) and
Eurostat's HICP (inflation adjustment) live and commits the result as a
snapshot, so nothing needs downloading by hand for those. The EFFIS per-fire
database is committed at `data/raw/effis_fire_database_pt_2008_2026.csv`.
The **ICNF PRDF GeoPackage** (`fogos.gpkg`, 943 MB) is **not committed** —
download it from Zenodo (DOI 10.5281/zenodo.21427772) and place it at
`data/raw/fogos.gpkg`; Phase 2-3 notebooks will not run without it.
